# liquidbiopsyR

An R package implementing advanced statistical models for liquid biopsy cancer detection, based on the paper "Advanced Statistical Models for Enhanced Cancer Detection Using Liquid Biopsy Data".

## Installation

```r
# Install from GitHub
devtools::install_github("Mayooran1987/liquidbiopsyR")

# Or install from CRAN (once published)
install.packages("liquidbiopsyR")

### User manual

This package’s user manual can be seen at <https://github.com/Mayooran1987/liquidbiopsyR/blob/main/dilutionrisk_0.0.1.pdf>
